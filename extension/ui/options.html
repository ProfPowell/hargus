HAR+ Options
Readings

Capture defaults

Views extra screenshots taken after each reading (about 30–60 s with all on)

Scoring

Weights set how much each area counts toward the overall score. If a critical area fails (F), the overall grade is capped at D.

Plugins

↗ marks plugins that send data off your machine. Each reading lists the hosts every plugin contacted.

API keys

Optional. Stored in this browser's extension storage and sent only to the matching service. A free PageSpeed key comes from the Google Cloud console (enable the "PageSpeed Insights API").

Remote plugins

Any HTTP endpoint that accepts a POST and returns { summary, findings, data } becomes a plugin. See docs/PLUGINS.md and examples/remote-lighthouse.
